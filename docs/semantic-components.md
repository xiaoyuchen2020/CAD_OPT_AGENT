2026-10-15。实现位于 `cad_agent/semantics/`，复用 `DrawingIndex`、原生实例 walker/ID、`native_source`、Shapely 空间索引、原文证据绑定、既有表格候选以及同一套 Agent 工具注册。没有调用帮图服务，也没有导入生产优化规则。

## 使用入口

网页「浏览结构 → 轴网、索引与楼层」提供五种候选列表、原图定位、筛选和分页。轴网列表可选择两条轴求交点、四条成两组平行的轴求轴区。索引列表可追踪当前图纸目标；跨图追踪在 API/Agent 工具中显式指定目标快照。

「浏览结构 → 表格 → 查看表头、单位与合并关系」提供语义视图。原始 `read_table` 行为保持不变，语义网格不可靠时可继续读取原文。

| Agent 工具 | HTTP POST（前缀 `/api/drawings/{snapshot_id}`） | 主要参数 |
| --- | --- | --- |
| `query_annotations` | `/semantics/query` | `kind=axes/references/leaders/elevations/storeys`、`layout_id`、可选 `frame_id/bbox/query`、`offset/limit` |
| `locate_by_axes` | `/semantics/locate` | `layout_id`、2 或 4 个明确 `axis_ids` |
| `trace_detail` | `/semantics/trace` | `layout_id`、`reference_id`、最多 4 个显式 `target_snapshot_ids`、分页 |
| `read_table_semantics` | `/semantics/table` | 既有 `table_id`、可选连续 `header_rows`、`row_offset/row_limit` |

## 能力与边界

### 轴网

组合原生圆、圈内文字与共线长线，保留轴号、圆心、半径、轴线、线型、支持实体及备选线。带上下分栏文字的索引圆不作为轴号。重复轴号保留不同实例，不按名称合并。

定位使用用户或 Agent 选择的明确对象 ID，按无限延长线求交。平行、退化、错误布局和外来 ID 明确拒绝或返回 unresolved。轴区不代表房间净边界；跨子图的同名轴线不会自动对齐。当前未重建弧形轴网、无圆轴号和断线轴网。

### 索引、引线和详图

支持分栏索引圆及明确的 `详见 1/A-01` 类文字。保留详图号、图号、连接线及来源。

引线包括原生 LEADER、满足连接和方向约束的三角箭头与线段、索引圆边缘连接线。原生关联与邻近文字分别记录；端点只给几何位置，不确认它指向墙、门或其他构件。索引引线中的剩余折线段不自动追踪，MULTILEADER 当前未组装。

详图追踪支持同段编号标题、独立圆圈编号与带下划线标题，以及编号圆加比例的无标题标记。复用原生 CIRCLE、由两段半圆 bulge 构成的闭合 LWPOLYLINE、表格图签字段和闭合图框；不以最近文字自动完成链接。独立编号圆优先于标题中的变体号，例如“18 / 排水沟大样4”。仅有编号与比例时明确返回 title_state=unresolved。不明确的图号保留 `candidate_sheet_unresolved`，多个候选保留歧义，无目标返回 unresolved。跨图只搜索显式提供的已导入快照，目标文字记录自己的快照、哈希、实体与坐标，不冒充当前图纸原文证据。

### 标高和楼层

支持数值文字与朝下三角符号组合，三角形可以来自实体或三条端点相接的线段。保留原始数值、明确写出的单位，以及文字明确声明的绝对/相对、建筑/结构类型；未声明则 unknown。

识别楼层标签和简短平面标题，归一化首层、中文层号、B2F 等层号。楼层和同一标注行的标高保留候选关联及所有竞争项。未确认同楼栋、基准和单位时不计算层高；当前不提供自动完整楼层体系重建。

### 表格语义

复用现有表格包围范围，从格线恢复矩形合并单元格。跨行单元格保持同一 ID 和 `continuation_of`，不复制为多个独立值。支持多级表头候选路径、表头来源、显式单位及单位冲突。原文 `0.9m` 与表头 `mm` 同时出现时保留 conflict，不静默选单位。

只有明确的编号/型号表头才触发同编号文字关联；关联仍不证明门窗实例身份或数量。表头自动识别是启发式，可通过连续 `header_rows` 明确选择。空白不向下填充，不采用 DWG 的绘图单位作为表格数据单位。

范围内外穿越的背景线不作为格线。语义网格坍缩、过大或非矩形组件保留失败/诊断；无边线表格、旋转表格、复杂不规则合并和跨表续表尚未完整支持。

## 2026-10-15 上一批修复与同批对照（v1.3）

该批源码版本：`native-dxf-v3.3-attdef-display`、`detail-trace-v1.3`、`table-semantics-v1.3`。旧快照保留不变，已有图纸须重新导入才能应用属性定义文字修复；本次四份输入已生成新快照，原 DWG 转换件 / DXF 字节未变。

原因与修复：

1. 独立 ATTDEF 的显示文字为 tag，旧解析错取默认 text；例如显示18、默认3，以及显示C、默认A。现在与既有渲染器采用相同规则，INSERT 内 ATTRIB 继续读取实例值。6个原索引的编号或图号因此被纠正。
2. 详图目标常是独立编号圆及标题，圆形还可能由两段半圆多段线组成。新增组合识别；有编号及比例但无可解析标题时只返回标记，不编造名称。
3. 图号常在图签相邻单元格中。复用既有表格行与闭合图框关联字段和值；排除明确图号冲突及跨图框“本图”错误关联，保留真正多目标歧义。
4. 图签签名/徽标短线原先被提升成格线；续表列线则因延伸超出局部范围被删除。现在用既有单元格边界作锚点，并恢复由侧边及同宽横线支持的完整列线范围；保留部分横线形成的真实合并格。
5. 多格内部密集长线、非矩形缺边连通区域不再静默返回不完整网格。保留原文入口和具体诊断，不将建筑平面图/剖面图当作恢复成功的表格。
