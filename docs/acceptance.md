# 里程碑一验收记录

日期：2026-10-14。范围：通用砌体做法来源记录、事实查询、DXF 证据定位及 Web 工作台。**工程验证结果，不是 AR024 业务验收或生产回归。**

## 合成样例

`cad_agent/demo.py` 生成可再分发的 DXF：29 个原生文字实体、17 个来源区域、9 条材料记录，其中 2 条缺少范围或等级，需要核查。含说明段落、地上内外墙、地下内外墙、卫生间、墙脚、B05 和两条网格表格记录。

| 验收动作 | 应见结果 |
| --- | --- |
| 打开示例 | 9 条记录，显式显示“合成示例” |
| 查询“列出地上内墙材料” | 4 条带引用记录，包含卫生间和 B05 |
| 筛选“外墙” | 2 条记录，地上与地下均保留 |
| 筛选“待核查” | 2 条记录，缺失项有标签 |
| 点击 100/200 厚的 B06 条款 | 保留 B06、A3.5、Ma5.0、100/200，原图高亮对应实体 |
| 搜索 B05 | 找到原始 B05 条款，不应用优化筛选 |
| 原文检索 | 可查阅所有已解析来源，包括没有生成材料事实的文字 |
| 询问优化/合规 | 明确提示未接入策略，不生成业务判断 |

## 自动化测试

执行 `python -m pytest -q`，本次 **47 项通过**。涵盖：

- 原文 span 回读一致，证据 entity/bbox 属于同一 snapshot。
- 同内容不同发生位置、同名图框、跨布局、嵌套块和 MINSERT 阵列保持身份独立。
- 有边线表格跨格聚合、碎片分隔符、B06A3.5 连写、厚度备选值。
- 缺失值保留 unknown，矛盾等级和标题不猜测；跨图框不继承；“其余”有来源链。
- 材料提及、引用、禁用与选用分别标记；界面剂不作为砌体材料。
- 拒绝模型虚构来源、重复歧义引用、半条款遗漏；保持本地候选。
- 协议请求结构、错误脱敏、模型未配置/失败/不完整响应、失败后保留原事实。
- 上传错误、大小限制、Host/Origin 校验、原文件下载、跨快照事实隔离与缓存。

前端 `node --check web/app.js` 通过。实际浏览器检查覆盖示例生成、四条事实问答、引用定位和 SVG 高亮；最终截图保存在本地 `artifacts/`。界面检查不是完整浏览器自动化回归套件。
