# cadoptagent 通用几何分析改进方案

本方案将 2026 年 10 月 27 日的辅助实验转化为通用图纸事实分析能力。核心分工是：模型提出对象和边界假设，工具读取原生几何并完成确定性计算，校验器说明哪些数值和表述有证据支持，任务状态系统保存进度与缺口。身份或单位未完全确认时，仍可交付带条件的局部测量。

本文最初作为实施方案建立，现已完成三阶段首轮实现和逐阶段实图重试，详见[实施记录](/Users/vigorchen/Documents/WorkExplore/cad_opt_agent/docs/geometry-agent-three-stage-results-20261028.md)。完整路线识别、物理口径和跨图纸泛化仍未完成。最初代码核对基于 2026 年 10 月 28 日提交 `e3e3316c20fa1764894cc402598ebaf7a1ef1a9a`。能力保持在图纸事实、空间关系和测量范围内；规范符合性、优化建议和工程身份确认不由数值计算自动推出。

## 实验能支持的判断

实验得到 5 个可以独立复算的局部候选宽度，依赖 13 条引导、通用几何辅助库、人工上下文整理以及监督者指定最终候选边界。39 轮 API 响应、25 次代码执行中有 5 次非零退出。它暴露了对象归属、几何运算、范围覆盖和状态管理的问题，但不能证明关闭校验器或增加用量的独立收益。

尤其需要区分实验工具集与产品能力。实验运行器只开放了 9 个原生检索/读取工具，另加 Python 与图片查看；没有开放现有 `measure_spatial_sections`、`bind_spatial_object`、`measure_spatial_relation`、`render_region` 等工具。实验中模型反复手写基础几何，不足以证明产品没有对应实现。第一步应接通现有工具，再判断剩余缺口。

实验过程使用过的实体句柄、坐标、对象数量、图层名、图名和预期宽度只属于回归样本。最终指定五对边界的那条引导不能写成通用提示词，也不能作为自主识别成功的训练式示例答案。

## 四类职责

| 类别 | 应负责的内容 | 不应承担的内容 |
| --- | --- | --- |
| 工具与 SDK | 原生读取、变换、候选生成、距离/截面计算、测线与证据图、具体诊断 | 依据图层名或数值接近预期，直接确认对象身份和完成面 |
| 提示词与任务方法 | 选择调查顺序、提出并修正对象假设、决定需要哪个工具、解释具体缺口 | 让模型背公式实现几何内核，塞入样本句柄或固定坐标 |
| 校验器 | 检查来源、计算前提、结果一致性、单位、范围与结论是否匹配 | 替模型猜正确对象；因为身份未确认而禁止所有局部计算 |
| 任务状态与运行配置 | 保存已读集合、对象假设、测量版本、覆盖缺口、预算和辅助记录 | 用越来越长的历史消息代替状态；让校验失败无限重试 |

前三类之外必须单独保留任务状态层。实验中的重复读数据、旧错误结果回流、空结果覆盖已有测量，都不能只靠一段提示词解决。

## 应产品化的工具能力

以下是拟议接口能力，不是已经存在的工具名。尽量扩展现有工具族，避免把每个底层函数都暴露为新的模型工具。

### 原生几何包与读取回执

将 `gh.load` 的使用体验封装在现有 source/service 之上。输入为快照、布局、已读取范围或实体集合、容差策略；返回 `geometry_bundle_id`、紧凑清单及按需读取入口。大坐标数组留在产物中，不反复进入模型上下文。

每个实体保留 `entity_id`、根句柄、稳定块实例路径、坐标系/变换依据、原始类型与参数、计算表示、近似误差、读取状态。运行编号或虚拟实体枚举下标不能单独作为跨轮稳定身份。尺寸标注通过原生尺寸读取返回实际测量值、文字覆盖、样式缩放及对象端点候选。

覆盖回执至少区分：请求范围、实际已处理范围、分页完成情况、被截断图元、无法定位或不支持图元、加载错误。`empty`、`unsupported`、`failed`、`partial` 不合并。边界实体触及窗口时产生调查建议；不能仅凭全部分页读完宣布目标完整。

实验 helper 不能直接复制入正式代码，至少要移除以下假设：

- 固定 `/input/drawing.dxf` 和字体路径，改为宿主绑定的快照与运行资源。
- 固定 modelspace，明确模型空间、布局及视口变换的适用范围。
- 默认离散容差 1 和截面半长 20000，改成显式坐标单位容差及源几何范围计算；未知单位下不能默认 1mm。
- 仅取 XY、直接使用 ARC 原参数，先核对 OCS/WCS、平面和块变换；非均匀缩放后的圆弧可能是椭圆，不能继续半径相减。
- `layers=['WALL']` 一类硬过滤。图层可作为检索特征，候选加载应保留其他图层，并解释纳入/排除。
- 用包围盒相交代替精确范围判断或覆盖证明；现有宽相位索引用于候选发现，最终计算使用实际几何。

### 图示与边界候选

复用 scope/object 机制，添加图示层级：同一图框中的平面、顶板、剖面、详图分别建候选记录。依据来自实际标题、标高、引线、空间分组和视觉解释；保存冲突而非只输出一个置信分数。

对线、弧、尺寸端点生成边界配对候选。工具给出平行/同心误差、有限重叠区间、尺寸端点到候选面的距离、连续性、交叉关系、图示归属及邻接证据。排序不能以“更接近规则阈值”为目标，也不能固定墙厚或道路宽度排除其他候选。

模型根据这些证据选择候选，保存 `selection_basis` 与 `selected_by`。同墙两面在几何上也可能平行或同心；几何条件成立并不证明它们位于通行区域两侧。可返回多个候选宽度和具体待核项，不强制选一个。

### 有明确测量口径的计算

| 口径 | 输入与计算前提 | 输出 |
| --- | --- | --- |
| 有限路径最短距离 | 两组有效源路径 | 最近点、距离、交叉时的零值；不改称断面宽度 |
| 平行直段法向间距 | 两条有限源线、平行检查、有效纵向重叠；测线端点落在两条有限线上 | 法向间距、重叠区间、测线、方向依据；无重叠则不外推 |
| 同心弧径向间距 | 在同一计算平面内同心、真实角区间相交；处理跨零度与反向变换 | 半径差、共同角区间、径向测线和角度；椭圆/不同心时返回不适用 |
| 局部横断面 | 路线局部切向、横断面与选定边界的真实交点 | 有符号交点、有效区间、选定自由区间与多解；不能默认取排序中相邻两点 |

数学函数应集中维护，模型只组合调用。把方向公式再重复写进系统提示词，无法替代经过测试的实现。现有 `measure_spatial_sections` 是直段与指定障碍处理的起点；曲线需要新增局部切向或径向参数化。

### 路线覆盖和障碍影响

新增任务内 `route_hypothesis`：源支持的入口、出口、直/曲分段、分支和转折，附上候选状态。路线不是以标题距离或一张裁剪图自动确认。每个分段记录已测区间、未测区间及原因，并保留过渡点两侧。

初期先支持分段线和圆弧，输出宽度剖面、最小已测位置、交点歧义和未覆盖区间。采样按边界顶点、候选障碍端点和曲率变化细化；任意步长采样仍只能报告采样最小值。只有受支持几何类别内的极值算法或可证误差界才能支持范围内最小值声明，不能把“采样点足够多”改写成证明。

障碍工具先做范围候选检索，再计算与通行带的精确投影关系，保存剖面、标高、基准和图示关系。高度状态分为明确同高度、明确不同高度、未知：同高度才作相应扣减；未知则并列保留“未计此候选障碍的边界宽度”和“若该障碍同高度则产生的影响”，不能输出无障碍结论。

覆盖率的分母来自某个明确的路线假设和参数区间，不能用已成功的断面数当全程分母。即使某候选路线全部测完，也不自动证明原图所有相关路线已找全。

### 证据图与生成代码 SDK

扩展 `render_region`，按测量回执叠加选中实体、测线、候选编号、坐标、单位状态、未覆盖区和障碍候选；保留周边标题或图示定位入口。线型、图层和标注作上下文展示，测量仍来自源几何。

沙盒 SDK 复用同一原生几何包和上述运算函数。模型可以编写候选筛选、分组、分段、参数试验及结果汇总代码，暂未收编的算法也可作为实验性结果保存。执行成功只产生执行产物，不自动授予几何正确或身份确认状态。

沿用现有不可变输入、版本、执行回执、取消与产物管理。新增几何程序契约应支持精确源引用、选定路径、变换参数、测线和结果类型，不要求把所有探索过程先限制为固定几种算法。宿主独立检查可核对的局部结果；暂无法核对的实验性结果仍可展示，但明确标记。经过跨图纸验证的稳定基础算法再收编为正式工具。

## 应放入提示词的内容

新增按需加载的几何任务方法，保留文字任务的默认路径。提示词只指导调查和证据使用，不包含本次样本的规则编号、图名、方向位置、句柄、坐标、数量或目标宽度。

建议的任务方法正文如下：

> 先确定用户所问对象对应的图示、布局和范围；同图框可以包含多个对象和不同图示。来源尚有歧义时保存多个候选，不因共用图框而复制测量结论。
>
> 优先读取和复用原生几何、尺寸及已有测量回执。图层名、邻近标签和尺寸端点只用于提出候选；将对象假设与计算结果分别记录。规则阈值不能用于挑选“看起来正确”的几何。
>
> 先用确定性工具得到一个有来源的局部结果，再扩展到具体未覆盖段。单位未确认时可以计算原图单位量；结构面或完成面未确认时仍可报告所选源面的间距和条件。不要将所有字段写成unknown后结束调查。
>
> 沿路线查看入口、出口、过渡、转折和潜在障碍。缺少对边时检查范围、图层和图示关系；不能把同一侧的另一条线补作对边。平面投影交叠先调查高度关系。
>
> 现有工具不足时，在授权沙盒中调用 SDK 编程。读回执行产物和诊断，再决定下一步；文件名、退出码和代码描述不证明任务完成。重复失败应针对具体前提修改，不反复生成同一最终报告。
>
> 每个结果写明对象假设、来源、测量口径、覆盖范围、单位/面类型条件及具体缺口。区分局部值、采样最小值、可证范围最小值和工程意义上的净宽，并记录人工辅助。

长篇几何公式、异常栈解释和旧失败历史不常驻提示词。工具返回与当前错误相关的短诊断及可执行下一步；状态工作集只带最新事实和仍有效的候选。

## 校验器如何调整

将检查结果与运行是否继续分开。每项检查返回 `check_id`、检查对象、结论、证据、影响范围及建议；失败应首先限制受影响的测量/声明，不使整个任务丢失已成立的结果。

| 检查层 | 例子 | 开发探索模式的处理 | 稳定交付模式的处理 |
| --- | --- | --- | --- |
| 执行隔离与来源完整性 | 未授权文件/网络、快照不匹配、源实体不存在 | 阻止该执行或拒绝该引用，保留其他产物 | 相同 |
| 确定性几何前提 | 零方向、无有效重叠、测线不落在选定面、同心条件不成立、非有限数 | 返回精确错误及已知参数，允许换候选继续 | 同时拒绝受影响的数值声明 |
| 单位与算术 | drawing_unit被写成mm、扣减假设冒充实测、计算不一致 | 记录问题并保留原始值或显式条件结果 | 限制单位换算或该条声明，不禁止原图单位测量 |
| 范围与对象关联 | 跨图示无对应依据、裁剪截断、候选归属冲突、障碍覆盖未知 | 旁路记录，结果保持candidate/partial | 不允许提升为“完整”“全程最小”“无障碍”；已核对局部值可交付 |
| 启发式语义 | 怀疑车辆符号、同墙双线、顶板/剖面归属 | 输出候选解释与复查位置 | 先保持提醒，验证低误报后再考虑对明确越界声明阻断 |

不使用一个总分决定整份答案生死。来源绑定、数值正确、身份、单位、范围和障碍覆盖是不同维度；一个检查通过不能替其他维度背书。注册程序跨两张图纸运行成功，也只是一项复用证据，不能证明工程语义泛化。

两种模式共用同一批检查，只改变处置策略。开发时允许关闭交付门禁或让语义检查旁路；无论模式如何，诊断与原始产物仍保存。校验器不得给出期待宽度或样本正确句柄作为修复答案。

## 任务状态与运行配置

复用现有任务和观测存储，增加几何工作集，至少包含以下相互独立的记录：

| 记录 | 主要字段 |
| --- | --- |
| 图示/对象假设 | 来源范围、标题/标签、图示类型候选、楼层/标高、实体集合、冲突、选择者 |
| 几何读取 | 快照哈希、范围/实体选择、工具版本、容差、已读页、诊断与几何包引用 |
| 测量 | 对象假设版本、边界引用、算法/代码版本、输入参数、测线、数值、单位、误差/近似、条件 |
| 路线覆盖 | 路线假设版本、分段、已测/未测区间、采样策略、障碍关系与缺口 |
| 产物版本 | 当前版本、替代关系、失败尝试、模型/工具/人工辅助来源 |

产物不可变，新结果通过 `supersedes` 指向旧版本；空结果不删除旧测量，旧测量也不能因仍在磁盘上就继续充当最新结论。大数组和图片按需读取，范围等价的查询可以复用；版本、容差或返回内容不同的结果不能静默合并。

进度以新增有效候选、完成测量、修正错误前提或减少具体缺口表示。把“读取更多字符”和“又生成一个final文件”当成进展，会鼓励无效循环。重复失败时给出此前尝试摘要和剩余选项，不靠追加同一句警告推进。

预算、校验和代码权限分别配置：`budget_profile`、`validation_mode`、`code_execution_mode` 不绑定为单个严格开关。研究模式可显式放宽任务用量与耗时，并持续记录消耗、取消状态和服务端限制；日常模式根据实测资源曲线设置。保持已有默认订阅通道，API仅在用户或运行配置明确选择时使用，不自动产生付费回退。

所有模型通道共享工具定义与结果状态，但分别确认图像、动态代码和推理参数支持。运行清单固定模型、通道、推理设置、工具集、代码提交、镜像和输入哈希。后续对照使用独立checkout，避免共享目录变化影响复现。

## 分阶段实施

### 第一阶段 接通已有能力并形成局部闭环

工作包：统一几何任务工具集；复用原生几何包、对象绑定、直段测量和渲染；补充同心弧的精确局部计算与适用性诊断；引入最新结果/失败记录及短几何提示词。启用旁路检查，不新增完整路线门禁。

验收分两层：给定实体选择时，直线与圆弧局部测量可靠、可复算、可视化；不给实体选择时，记录模型自主候选选择的实际表现，不将计算层正确当成识别层成功。明确错误输入必须返回具体原因，未知单位不阻止原图单位值。

### 第二阶段 减少人工选边并建立路线覆盖

工作包：同图框图示分离、候选边界生成与解释、分段路线、过渡/端点覆盖、已选障碍的精确影响和高度关系。先覆盖直线与圆弧构成的路线，其他曲线明确能力边界。

验收：未提供句柄/坐标/期待答案的持出图纸上，能保存独立对象清单、测量剖面和具体缺口；能识别部分路线未读、对边缺失和高度未知。评价人工干预次数及候选选择准确性，而不只统计最终有多少数字。

### 第三阶段 稳定后逐项收紧与优化用量

工作包：检查器按类别评估误报与检出效果；低误报数值/来源检查先用于局部阻断；跨图示和覆盖检查只阻止超出证据的表述。针对重复请求做缓存、结果投影和摘要；依据真实任务记录调整预算。

验收：相同模型、推理设置、输入和工具版本下比较旁路与阻断配置。随后另做预算对照，避免同时改变多个因素。记录成功率、局部正确率、覆盖、错误自信结论、干预次数、调用量、缓存量和耗时。

## 避免样本硬编码的验证

原实验作为开发回归样本保留；通用效果必须使用未参与引导的图纸。建议首轮至少选 6 张独立图纸，覆盖不同来源与绘图习惯，并保留一部分作为不参与提示词调整的持出集。该数量只是首轮方案，不代表统计充分。

必须同时有以下测试层：

1. **几何性质测试**：平移、旋转、镜像不改变相应距离；合法统一缩放使长度按比例变化；拆分/合并共线线段或同圆弧不改变同一几何范围内结果。改变标注文字或删掉误导尺寸，不应改变源几何计算。
2. **边界条件测试**：跨零度圆弧、嵌套块、bulge、闭合边、非均匀缩放、非零坐标原点、无重叠、零方向、交点多解、缺失对边、截断范围和不支持实体。返回近似或不支持时必须有依据，不能默默当精确。
3. **语义与范围测试**：同图框多对象、同名不同楼层、平面/顶板/剖面并排、车辆和图例、隐藏边界、不同高度投影重叠。原图单位未知、条件单位、结构与完成面分别评价。
4. **去线索测试**：重编号句柄、重命名图层、移除相同文件名和绝对路径。图层语义消失后可以更不确定，但不能凭空确认或依靠原样本键值恢复答案。禁止按规则阈值反选候选。
5. **识别与计算分离评估**：一组提供独立标注的实体对，只测工具数学；另一组不给实体对，只测完整自主流程。参考答案由原图独立核对，不使用模型自己的候选结果充当真值。

指标分别报告对象/图示归属、选边正确性、局部误差、路线覆盖、单位错误、错误全局结论、人工辅助次数和资源消耗。覆盖率必须注明参考路线是否独立标注；没有可信分母时报告已测/未测段，不编造百分比。

## 建议首批交付

先完成“读取源几何 → 选择候选 → 得到局部测量 → 回看证据图 → 保存具体缺口”的最小闭环，并提供一个 API/订阅均能明确声明能力的实验入口。把正确局部计算、识别质量和完整路线覆盖分别验收。

这一顺序吸收了实验中有效的帮助，也保留了探索自由：模型能先算出有条件的事实，工具承担重复易错的数学，校验器帮助限定结论，通用性由跨图纸证据来建立。

### 运行流程

1. 先界定图纸、对象/图示范围和要回答的事实，单独标注参考边界、数值及覆盖全集。原图哈希、问题、标注依据与评分维度一起冻结。未标注的项目不得默认计为正确。
2. 探索运行允许监督与动态修复；每次介入写明类别、涉及对象、证据来源。不得把直接给出的句柄、坐标和正确宽度计作自主发现。
3. 根据首次错误决策修复通用能力，保留失败轨迹；用原图及不同来源图纸回放计算和来源链。
4. 业务验证使用未参与引导的图纸和预先冻结的对象级金标准。已经看过或用于调参的图纸只能作为开发回归。
5. 验证校验器时只改变校验模式；优化上下文或预算时另做独立对照。记录每次输入/输出/已报告缓存 token，缺失字段保持未知；没有核实该渠道单价时不编造成本。

工具迁移回放与对象级业务评测是两种不同证据。本轮三张实图回放检查的是原生几何、来源和调用链，并没有建立完整坡道金标准，不能报告为三图自主识别通过。
