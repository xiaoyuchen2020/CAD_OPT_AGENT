## 主要修正

| 问题 | 修正前 | 修正后 |
| --- | --- | --- |
| 真实 TEXT 碎片 | 根据替代字体 bbox 判断，句子被截断 | 原生插入点、栏边界、行距和条款编号约束阅读顺序；跨行保留原始实体映射 |
| 表格内多行备选 | 按 x 排序混合砌块与钢筋混凝土行 | 按单元格和基线分别阅读；明确表头矩阵仍可合并属性列 |
| 隔声表厚度 | 15、200 同时成为墙厚 | 200 为砌块厚度；15 和 DPM15 为两侧抹灰，不作为墙厚/砌筑砂浆 |
| 住宅其他内墙 | 缺失下一行 M5.0 | 同条款续行纳入，B06/A3.5/100或200/M5.0完整保留 |
| 女儿墙 | 强度止于“强度”，缺失 A5.0/M5.0 | 续行找回参数；混凝土或砌块备选仍标记复核 |
| 消火栓洞后砌筑 | 仅识别“混凝土砌块” | 拼回“加气混凝土砌块”；100 为洞后砌筑厚度，240 主体墙/160 栓箱深度排除 |
| 适用范围 | 丢失住宅/公建标题 | 章节层级范围、例外限定与标题证据绑定，同级标题终止继承 |
| 同一条款内外墙参数 | 漏掉分号后的内墙参数 | `role_parameters` 保留分角色厚度/等级，复合顶层字段标记待核查 |
| 材料检索 | 从原文匹配等级，可能命中抹灰等级 | 查询提取后的属性；按内外墙角色选择对应参数，住宅不匹配“除住宅外” |
| 证据框 | 整个段落或整行表格 bbox | 按引用字符范围选择原始实体；返回多个实体框，保持字体估算精度声明 |

样本差异单独保留：59 标题限定“非地下室室内部分”，60 为“地下室室内部分”；60 的内墙原文还删去“底部”。61 与 62 的公建外墙、地下室内分隔墙材料不同。60 的“室外部分”与其上级标题之间存在解释歧义，原文、标题和未知墙体角色均保留，不能直接作为工程结论。

## 模块与接口变化

- `cad/regions.py`：阅读栏、基线、保守续行、表格单元格、编号章节范围。没有样本编号、原始 handle 或工程策略分支。
- `contracts.py`：新增 `SourcePart`。区域 `parts` 保存区域字符范围 → 原始实体字符范围及实体 bbox；`column_key` / `table_row_key` 保存关联边界。
- `evidence.py`：证据 `source_parts`、`component_boxes`、`entity_ids` 仅覆盖与引用相交的来源片段；MTEXT 仍使用整个实体框，不伪造子句精确坐标。
- `building/masonry.py`：通用材料词表、施工阶段参数归属、章节范围、分角色参数及复核原因。新增属性 `application_scope`、`scope_qualifiers`、`role_parameters`。
- `analysis/query.py`：查询规范化属性、限定章节范围和角色参数。
- `web/app.js`：显示适用范围及分角色参数；按多实体证据高亮，并缩放到实际局部。

工具/API URL 不变，新增响应字段向后兼容。解析快照版本为 `native-dxf-v2-reading-order`，抽取内部修订为 `masonry-v1.1.3`；公开工具名仍是 `building.masonry@1`。旧快照/旧事实保留，重新导入同一 DXF 会建立新版快照，不冒充旧结果已经升级。

## 已知边界

泛称“砌块”的子条款尚未自动消解为上级具体材料，复杂多层表头/合并单元格、旋转文字、无边框多栏及材料简称仍需扩展。不是所有文本提及都代表选定材料；不得仅根据记录数量计算准确率。单位未标明、图框未确认和部分未绘制图元的诊断继续显示。

当前字体缺失，DXF 原始文本与插入坐标可核验，bbox 仍为字体估算。报告插图是保留原始插入坐标、约束替代字宽的文字重建，不是原生 CAD 截图，也不支持工程尺寸量测。原始 DXF 保持不变，原图级视觉保真仍需匹配字体和更完整渲染链路。
