# 图纸编号与数值的统一解释

版本：`source-numbers-v1`；做法读取：`assembly-source-v7-numbers`。原图、原文及旧运行不重写，也不改变 CAD 快照身份。

## 数据流

`bind_evidence → region_readings → numeric_readings → 做法解析 / 数值校验 / 计算库存与计算工具 / 阅读视图`

`cad_agent/cad/numbers.py` 统一识别 ordinal、ordinal_reference、identifier、quantity、expression_component、ambiguous。每项保留原文 raw、规范 value、字符 text_span、number_id、解释依据和状态。来源记录另外绑定区域 source_span、原文 SHA256、版本，并通过既有 evidence 绑定快照、实体及几何。数字身份不证明对象归属或工程适用性。

全角数字和全角点只在等长投影中规范化。明确分隔符的编号可独立识别；紧连数字的点号须由从 1 开始且前两项明确的连续列表消歧。独立 `3.5厚` 原样保留为待核查。CAD 中独立 `3.` 编号实体与正文实体同区域、同基线且间距受限时，也能确认分界；跨列、错行、单纯裸数字均不能提供这种证明。

部分引用从完整区域继承解释，截取 `3.5厚` 不会丢失已确认的“编号 3、厚度 5”。原文 SHA256 或解析版本不匹配时重新解析，旧证据无需数据库迁移。无法恢复上下文的旧片段保持保守解释。

## 校验与计算

答案校验区分序号、序号引用、工程标识与数量；数量不能借用序号或材料等级的数字。标识按完整身份匹配。保留真实小数、符号、分数和源单位；同名不同图框、归属、单位、缺项等既有检查继续独立执行。原样引用完整证据时沿用来源解释，不把已消歧编号重新读成小数。

`calculate_facts.quantities[].quantity_id` 和内联 `calculations[].operands[].quantity_id` 引用来源 `number_id`。唯一确定数量允许兼容旧调用并由服务绑定；重复值必须明确选择 ID 或唯一来源片段。编号、型号、单个比例/范围分量、歧义项不可作为操作数。完整原文分数仍可用于既有内联算术。单位未知的普通数值只能保留原有“数值小计、单位未确认”语义，不能自动补 mm 或产生确定工程量。

计算库存复用来源解释与 ID，不能重新对证据片段扫描而改变含义。默认单位条款仍须绑定原始出处及适用范围。

## 展示和兼容

保存模型原始 `claims[].text`；服务器生成 `display_text`，把确认编号渲染为 `第3项：5厚…`。原文证据卡仍显示真实原文；显示编号不证明从内到外的施工方向。页面和 answer 使用规范阅读视图，恢复流程剥离服务端展示字段再校验，避免污染模型输入协议。

旧 `numeric_tokens` / `numbers` 保留为低层词法 API，供历史短语检查使用；它们不授予计算资格。所有算术入口、做法厚度提取及发布数值检查使用统一的语义记录。

## 验证边界

测试包括真实被拒草稿、编号拼接小数、括号/圈号/全角格式、负数、分数、型号等级、错误数值、重复值与单位错绑、证据截取、独立 CAD 实体编号、旧记录及结果恢复。完整测试与真实订阅结果存于 `artifacts/unified-numbers-20261023/`。

该版本没有建立通用视觉 OCR 消歧器；复杂排版和无依据的歧义仍需补读或人工核对。数值校验通过不等于工程语义完整或穷尽全图。
