## 1. 任务路由与范围

实现：`cad_agent/analysis/source_record_query.py`，复用原任务拆分和任务 ID。

- 提取对象族、动作、当前/选定图纸范围、明确字面条件、全部来源要求；保留每个问题部分的原文与 ID。
- 支持做法编号，以及用引号明确的含、不含、排除、标题、编号、图框条件。引用里的“内墙”等字样不会变成新的检索对象族。
- 单一前置问题的追问继承对象、编号和条件；图纸范围变化或多问歧义回到原 Agent，不擅自扩大前提。
- 不把图框名称当成工程适用对象。未识别约束、数值比较、计算、工程判断和几何问题不被静默忽略。
- 语义比较先整理来源再交回 Agent；明确“并列”的请求直接按来源并列，保留同号异物。

验证：路由/追问单元测试，真实图纸的双问题、编号筛选、无结果、跨图与追问测试。

## 2. 共享来源记录与缓存

实现：`source_record_store.py`、`source_records.py`，接入原 `read_assembly`、编号数值解析和证据账本。

- 原文、快照、区域、字符范围、表行归属、表头、备注、单位候选和读取页保持可追溯。
- 分页完成、来源绑定、引用依赖、工程适用性是四个独立状态；读完原文不会自动确认工程适用性。
- 缓存绑定快照、源内容哈希、解析/数字版本、读取参数；命中后仍逐条核对证据 ID、原文和范围。缓存不授予未读证据或任务完成信用。
- 读取期间源版本变化时停止发布；不能通过切换运行时绕过这一保护。
- 保留序号与真实数值区别，复用原显示层生成“第3项：5厚”，不改写证据原文，也不自行把“5厚”补为“5mm”。

验证：缓存命中、版本失效、篡改原文、源版本变化、序号/小数、相同文字不同来源，以及原证据/单位回归。

## 3. 完整记录检索与资料包

实现：`source_records.py`，以及 `assembly.py` 的多标题边界、同族目录和几何索引复用。

- 标题命中按明确段落边界读完整记录；无编号表格必须有明确行、身份列和表头绑定。
- 正文关键词命中尝试回到所属表行。无法确认归属的命中保留坐标与后续读取动作，不混入做法层次。
- 同一区域的多个标题用字符起点分离；同编号不同来源不合并；跨图保留独立记录和证据身份。
- 翻页核对连续偏移、总数、记录身份和绑定；不截取半条记录充当完整结果。
- 明确且唯一的编号引用继续读取，并检查循环与歧义；较晚记录引用到前面已排除的记录时也会补读其依赖。节能专篇、效果图等未能定位的引用保持未解决，并保留项目来源核查动作。
- 资料包使用短引用标记、公共范围上提、同文只发送一次、完整记录分包。相同文字不同来源保留各自引用身份。
- 记录/页/工具/时间/模型轮次均有上限；预算不足保留已读证据交回原流程。固定读取的临时子任务额度在返回和异常时清除，不改变原 Agent 的探索额度或停滞规则。

验证：真实同号外墙、多图17记录、无编号表格、剖面说明，以及多标题、跨页、引用链/循环、资料包预算与注入文本测试。

## 4. 受约束回答计划

实现：`source_record_answer.py`、`source_record_selection.py`、`source_record_workflow.py`。

- 自动模式不需要模型调用；复核模式让模型输出逐记录决定和顺序，可标注本记录中的逐字引文。
- 明确筛选由程序执行，排除结果可审计。模型不能遗漏记录、擅自排除命中项，或改变候选/已确认的状态。
- 正文由程序从完整来源展开，按来源分组；不是让模型重新抄写所有材料和数值。
- 模型解释与记录决定分开校验。解释错误不会擦掉已经通过的决定；每包最多一次局部修复，只发送需要修复的记录。
- 长记录按原单条结论限制拆分，保留引文，不截断小数、代码和数量。普通模型的答案大小限制不放宽；仅会话内按摘要绑定的程序答案允许更大聚合。
- 最终仍经过原数字、单位、计算、出处绑定、任务交付和引用校验。任何篡改后的草稿不能使用程序交付许可。

验证：遗漏、重复、未知 ID、错误排除、候选升级、解释越界、局部修复、长记录与交付许可测试；真实外墙未发生序号误判。

新路由默认开启，无需设置环境变量。`CAD_SOURCE_RECORD_WORKFLOW=0` 可显式关闭。`ChatRequest.source_record_mode` 可设 `auto`、`review` 或 `agent`，默认 `auto`；界面“问答设置”有对应选择。关闭开关或选择 `agent` 可使用原路径。记录/分页/资料包预算见 `Settings.source_record_*`，会话总预算仍生效。
