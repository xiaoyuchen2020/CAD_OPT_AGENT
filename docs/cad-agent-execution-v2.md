## 来源与发布

解析版本为 `native-dxf-v5.1-reading-streams`，做法绑定为 `assembly-source-v6`。匹配在原字串上保留偏移，引用不改写。物理宽列内仅在有相隔足够远的做法标题时建立候选阅读流；局部文字高度决定阈值。阅读流本身不是来源归属证明。

`read_assembly` 默认返回最多 12 个条目（一条逻辑记录内），不是多记录批读。明确章节、同列、编号序列和结束边界仍要经过原有检查；缺边界、编号冲突保持 candidate 和具体诊断。无法界定章节时不能把整列包装成完整做法。未确认的缺口通过表格或局部图像路径补查，保持原有尝试上限。视觉匹配不升级为工程确认。

`DeliveryManifest` 只选用已校验 claim 引用的 ID，记录 claim 使用关系、来源绑定、图框范围、实际要求状态和缺口。最终来源卡根据这份选择显示；调查材料继续保存在任务和运行档案中。只有标题不足以完成普通“找做法”要求。窄范围的跨类别守卫能拒绝把已绑定内墙正文归到外墙，但不是通用语义判定器。`source_bound` 与 `structural_checks_passed_semantics_requires_review` 均不表示模型所有解释已经正确。

## 进展、预算与上下文

`ProgressDelta` 分为 verified/candidate/diagnostic/no_progress。用源快照、位置、跨度和原文指纹判定内容，换 ID 不会产生新进展。无关来源、重复档案回读不能刷新要求进展。连续三次无进展停止该要求，独立要求继续；新诊断只提供有限探索。显式批读以内层来源进展登记，批次尾部不相关项不单独累积停滞，失败子项仍计入调用额度。

每项常规额度为 12 次调用，v2 只有 verified progress 可获得既有的额外 4 次余量；候选探索受常规额度约束。恢复任务保留来源与指纹，同时重新建立本次调用/停滞窗口，累计调用单独记录。

多图框升级依据实际搜索/读取结果，不升级模型档位。复杂几何继续使用既有标准/深度预算。服务端配置更低的限制仍优先；软阈值不代表充分回答。所有请求继续经过完整 payload（含 schema）的预算预检，保留成稿和一次纠错机会。 探索请求已获得来源后若在发送前触发token预留或单轮输入上限，会转入已有有界成稿上下文；拒绝请求记为未发送，不计虚构用量，既有用量继续计入。成稿再次经过同一预算预检，仍超限则明确失败，不重试原大包或放宽限制。

静态 instructions 和已曝光 schema 保持稳定；当前状态只留一份。超过输入软阈值时，用既有 bounded_packet 生成工作集；只有字符量至少减少 10% 才采用。保留最后一组完整 Responses 调用/返回，完整历史先归档，不调用额外总结模型。简单做法工作集保留原文和归属字段，省略逐字段重复的答案草稿模板；复杂交付仍保留既有模板。视觉和带 parent_run_id 的追问跳过这类新检查点。源范围、单位、例外、冲突和候选状态不得因压缩提升信用。字符减少不是官方 token 计量。

## 启用、迁移和回退

新高效任务默认 `CAD_EXECUTION_POLICY=v2`。`CAD_EXECUTION_POLICY=legacy` 或请求 `agent_policy=legacy` 可停用新提示/工具配置和按要求进展策略；旧任务没有 v2 标记时按旧策略恢复。安全的引用筛选、解析修复、动态状态去重不会因该开关恢复旧错误。

既有图纸不会在旧快照 ID 下重写。网页“重新解析图纸”调用已有 `POST /api/drawings/{snapshot_id}/reindex`，验证原文件 hash，在新解析版本 ID 下生成结果；原图、旧任务及证据保留。原 DWG 的转换结果复用，无需重新调用转换服务。相同版本重复操作幂等。新图纸导入自动使用当前解析版本。服务进程需要重新加载代码后生效。

默认 `source_read_batching=false`；只有显式 true 才曝光和执行批读。没有付费 API fallback、自动提升 reasoning effort 或外发遥测。实验复用原账号文件，不复制凭据到报告。

## 验证与边界

全量 Python 回归、Node 来源/运行详情回归、真实图纸确定性来源回放，以及同题前后三次订阅运行分别报告。新旧运行均使用同一原图 hash、GPT-6.1 Sol low、关键词检索、无选区、批读关闭。报告保留失败尝试与候选试验，不用最好一次代表全部结果。

用量来自服务端 usage；缓存输入包含在总输入中，不换算费用或订阅余额。精确跨度/引用集合通过不等于语义正确，报告还逐份核对实际回答中的范围、层次、替代项和缺口。三次小样本只报告逐次值和中位数，不估计 p95，不外推所有图纸的收益。既有二十题历史成绩不是本版新成绩。额外固定20题以原v1.1题目、原始索引和固定预算验证综合任务；完整首轮与上下文边界修复后的四题复验分别保存，不把混合版本当作一次完整最终版回归。六阶段版本全量Python回归1720项通过、4项跳过；Node回归51项通过。实际订阅成绩和全部失败用量见运行报告。
