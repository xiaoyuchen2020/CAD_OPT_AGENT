# 运行详情

> 2026-10-23 更新：v2 请求日志同时记录提示词版本/模块/hash、执行策略与预算策略，工具日志记录 requirement_progress。最终选中引用与调查档案分开；见 [v2 实现](cad-agent-execution-v2.md)。

模型问答开始后，右侧显示本次运行时间线；左侧保留图纸及回答。点击「专注查看」可以展开详情。问答区的「运行记录」按当前图纸列出历史任务，重新打开页面后仍可查阅。

记录来自实际运行的生命周期，不根据最终答案反推过程：

- 接收问题：本次范围、传入历史和应用系统提示词。
- 模型请求：原生网关、直接订阅、桥接订阅记录实际请求；公开返回包含工具调用和供应方明确提供的公开摘要。Codex 托管运行时只能记录应用提交内容，界面明确标注内部逐轮请求不可见。
- 工具：调用方输入、已验证的执行入口参数、返回给运行时的结果、完整工具归档及裁剪诊断。批量调用按父子事件保存。
- 校验：待校验草稿、程序返回的字段错误或通过状态。失败草稿不会作为成功答案展示；后续修复保留独立记录。
- 交付：待发布答案、引用和未解决项。是否成功发布以整个运行的最终状态为准。

「模型／工具／校验」筛选和搜索针对步骤名称与摘要；展开节点后可切换记录类型、分页加载和复制已加载内容。工具步骤中的原文证据可定位当前图纸；关联图纸提示先切换。输入图像保留本地图像引用，不在日志中保存重复字节。

逐步回看展示保存的步骤及最终状态，不重新执行工具，也不还原未记录的中间画面。旧运行仅显示原有 trace，缺失的提示词和完整返回不会补写。

## 数据与边界

事件摘要保存在 `chat_run.run_events`，正文单独保存在 `run_section`。轮询不携带大段正文；读取每页最多 12,000 字符，每节最多保存 2,000,000 字符，截断有明确标记。每节带摘要校验及 run/event/section 绑定。导出为 NDJSON，逐条包含运行、事件和正文。

认证字段、内部执行令牌、图像数据及私密推理内容不进入日志；公开决策摘要仅在模型实际提供时显示。日志本身含问题、提示词和图纸内容，沿用本机工作空间的保存和访问范围。运行详情不向模型增加上下文，不授予证据有效性，不改变模型、预算或失败回退策略。

工具成功和程序校验通过不代表工程身份、几何结果或合规结论已确认。耗时和 token 仅展示实际报告值。
