# 文字能力修复与验证（2026-10-20）

本次修复文字漏读、独立单位条款无法用于计算，以及交付校验误丢正确内容三个具体问题。没有扩大几何开发范围，也没有把未知项自动改为完成。

## 实现

| 问题 | 修改后的行为 |
| --- | --- |
| 通则、条件及编号续文漏读 | 新增按原始分项跨条款补读的工具，按句段排序，保留来源范围和分页；冒号引导句后连续编号的清单优先随文读取。续读入口进入任务记录，但不重置任务预算。 |
| “96厚”等数值缺单位后无法计算 | `calculate_facts` 支持单独的 `unit_evidence_id`。数值原文和默认单位条款分别保留，并贯穿计算来源链。局部条款只能在同图框使用；明确适用于本工程施工图或单体建筑设计的条款允许同快照、同布局跨图框使用。 |
| 正确内容在交付恢复时丢失 | 允许标明用户条件的 `unknown` 缺口说明保留输入引用；恢复时逐分项保留独立通过校验的完成结果。另一分项出错不会统一降级全部结果，未完成操作、未覆盖字段、被截断或无效内容仍不能算完成。 |

默认线性单位不能套用于面积、标高、坐标、材料编号、总平面专用约定或冲突单位。跨条款排序、同文件、邻近位置均不证明工程适用关系。没有数值、外部文件未提供、分母未规定等真实缺口继续保留。

- Q19 原始失败交付包回放通过：用户给定 10% 但分母未规定的具体说明保留为 `unknown`，没有把用户标签改成图纸限值。
- 相关回归首轮为 709 通过、3 失败、1 跳过；修复工具清单测试及不完整历史回执的兼容问题后，受影响的 **75 项重跑全部通过**。合并结果为该相关测试集合 712 通过、1 跳过。未宣称整个仓库全量测试通过。

| 题目 | 实际结果 | 仍保留的边界 |
| --- | --- | --- |
| Q01 | 最终正文恢复“基层含水率不应大于 9%”及“雨天及 4 级风以上天气不得施工”，带原文引用；27 处引用逐字绑定检查通过。 | 构造表行边界及适用范围仍有未确认项；材料兼容性在已读范围未查明。整题仍为部分完成。 |
