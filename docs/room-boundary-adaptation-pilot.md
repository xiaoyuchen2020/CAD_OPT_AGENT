输入为既有选中局部的原生线段、文本、源文件/解析文件摘要、递归 INSERT 可见性、原 DXF 的 INSUNITS 单位声明、目标公变原文及种子点。输出为目标环、逐边原生线段支持、声明排除的贯穿线 ID 和本地原点计算的面积。禁止凭空补边。具体契约见 `scripts/room_boundary_pilot_validation.py`。
