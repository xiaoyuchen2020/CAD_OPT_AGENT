# 数据来源总览

入口：`http://192.168.1.146:8080/source-overview/`。沿用任务中心登录，任务中心首页和结果页提供入口。

## 使用

选择任务，可切换当前任务或同项目来源、执行批次和历史采集批次。左侧按图纸版本列出来源，中间持续显示当前布局的全部来源高亮，右侧查看原文、提取数据、条件、事实包及规则输入关联。

- 点击来源只改变当前选择，其余来源继续高亮；“定位原图”才主动缩放。
- 已读取、已交付、已发布事实包、已选入分析分别标识。规则和分析轮次筛选依据实际关联；进入某轮输入包不等于模型实际使用了每项数据。
- 图纸哈希、节点、布局隔离，定位前再次校验。无可靠坐标的记录保留在“待定位来源”，不猜测位置。
- 保留测量线、端点、原始单位及未知条件；原文范围高亮不等于合规判断或完整工程对象确认。
- 自动同步每 15 秒触发，仅在页面可见且空闲时执行；保留缩放、平移和当前选择。来源密集时聚合显示，点击可展开。
- 只链接明确记录的证据引用，不用关键词相似度推断跨图关联。

## 数据与运行隔离

`source_overview.py` 从已有归档、证据回执、事实包和规则工作流投影来源，不触发采集、规则运行或模型请求。查询使用显式只读 SQL，不调用会回收租约的 FleetStore 任务读取接口或会创建数据库的 Store 构造器。

线上为独立 GET/HEAD 服务，监听 `127.0.0.1:8794`。Nginx 仅增加独立路径及首页入口，原任务中心、计算节点、worker 和当前主发布目录不变。来源服务限额为 CPU 40%、内存 512 MiB、48 个任务。认证通过原中心的 session-only GET 接口，保留现有会话撤销及过期语义。

生产数据目录保持 `ReadOnlyPaths=/var/lib/cad-atlas`。SQLite 主文件和 WAL 复制到服务专属 `/run/cad-source-overview`，复制前后校验文件身份及修改签名，通过 SQLite `quick_check` 后读取副本。包含 WAL 中已提交事务，不使用忽略 WAL 的 immutable 模式；原目录不创建 SHM，不持有数据库读事务。副本缓存 10 秒，实时执行身份校验强制重新检查。源文件忙碌或校验失败时拒绝本次读取并保留明确错误。

实时读取只使用节点的现有 GET 接口，每轮每个任务最多 8 次请求、约 5 秒预算，证据按字符游标续读，完整记录校验 SHA256 后才能展示。切换任务执行批次或节点后丢弃旧结果。单条实时记录上限 16 MiB；超限、读取失败、尚未获得运行编号均显示同步缺口，不能将其作为“全部读取完成”。历史数据缺少位置时也不会补造坐标。这里不提供整图覆盖百分比。

## 代码与发布

- `cad_agent/fleet/source_overview.py`：只读快照、归档校验、来源投影和规则关联。
- `cad_agent/fleet/source_overview_service.py`：独立认证、限流读取、原图代理。
- `cad_agent/fleet/static/source-overview.*`：来源总览页面及筛选模型。
- `web/source-overlay.mjs`：独立 SVG 高亮层；仅 `sources=1` 模式启用。
- `cad_agent/fleet/source_overview_support.py`：总览专属的只读归档格式解析，不导入可选结果面板和规则引擎。
- `cad_agent/fleet/source_overview_viewer.py`：仅适配独立服务返回的查看器脚本，磁盘中的 `web/app.js` 不变；接口变化时明确拒绝适配。
- `scripts/deploy_source_overview.py`：从当前线上版本复制独立发布包，再叠加本功能；部署前校验归档、原发布版本和服务状态，在已有维护锁下发布。

本次实现位于独立 worktree `cad_opt_agent_source_overview`，分支 `feature/source-overview-20261030`。`a7948e4` 是开始时其它工作区改动的隔离快照；集成时只应用它之后的功能提交，不要把整个快照合并回主分支。

2026-10-30 实际运行版本为 `/opt/cad-atlas/source-overview/releases/20261030-v4`，服务名 `cad-atlas-source-overview-v4.service`。持久单元已安装并启用；本次通过同配置 transient unit 启动，未执行可能加载其它修复单元变更的 systemd daemon-reload。部署和升级证据在 `artifacts/source-overview-20261030/`。

初版健康检查未覆盖 SQLite 读取，线上出现只读目录 SHM 错误；现已改为副本读取和实际数据库健康检查。曾提出扩大中心目录写权限的 v2 方案，被自动审批拒绝且未执行。v3 预检因繁忙数据库重复复制失败，未启用。最终 v4 保留原数据目录只读，仅写自身运行缓存。

回滚只涉及本功能：在维护锁内，核对当前 Nginx 和新增单元与部署记录匹配，移除本功能 `/source-overview/` 路由及入口注入，执行 `nginx -t` 后 graceful reload，再停止并禁用本功能单元。保留发布目录和记录供审计。不要还原整个 Nginx 配置、切换主 `current` 链接或重启中心/agent/worker，以免覆盖后续修复。

浏览器验证了合成图纸双图切换、规则筛选、全部高亮保持和刷新视口保持；线上 AR005 任务显示 20 处来源（6 处有坐标、14 项待定位），当前通用图 5 处同时高亮，选择单项后仍保留全部 5 处，原文和输入关联可查。发布前后 9 个原有中心/agent/worker 服务状态及 PID 相同，主发布目录未被本功能切换。这是展示与只读数据链路验证，不代表重新运行规则或通过业务基准验收。

## 主分支独立集成

2026-10-30 合并时，远端主分支仍为 `216ceb8`。原提交 `6b1b44f` 引用了其它任务尚未提交的结果面板、规则工作流及节点模块，因此不能直接摘取或合并它的快照父提交。本次只提取来源总览功能，所需纯读取函数放入专属 `source_overview_support.py`，查看器钩子仅在独立服务响应中适配，测试/演示用显式合成归档格式替代规则工作流写入依赖。结果页未安装时隐藏该导航。

集成工作区为 `cad_opt_agent_source_merge`。最终变更仅新增本功能文件，不修改主分支任何已有文件，也不纳入其它任务的未提交文件。干净主分支上的验证为 65 项 Python 和 15 项前端测试通过；本地真实 DXF 渲染验证全部 3 处高亮、单项选择、定位、刷新视口保持和双图切换。先前 79/19 项验证属于隔离快照环境，不替代本次干净主分支验证。

本次集成和推送不运行部署脚本，不访问或重启生产服务；线上仍使用已部署的 v4。部署脚本用于新装，遇到已有来源服务或维护锁会拒绝覆盖，不能直接用作线上升级命令。合并主分支不等于发布这一独立适配版本。
