# 统一模型上下文编码层

版本 `model-context-v1.2`。默认启用；设置 `CAD_MODEL_CONTEXT_CODEC=0` 可以退回原始模型表示。永久证据 ID、CAD 快照、原文字符跨度、实体定位及既有来源/数值/范围校验均不迁移。

## 边界与数据流

`完整工具结果/会话记录 → 模型上下文编码 → 模型调用 → 短 ID 还原 → 原工具入口/答案校验 → 完整引用交付`

`cad_agent/analysis/model_context.py` 是统一入口。Responses 直接运行时在预算估算和发送前编码；Native 与外部桥接使用 `session.model_messages`；托管 Codex 订阅在初始上下文、工具返回和最终整理包编码。各入口共用会话实例，工具参数和最终答案在 session 入口还原。协议历史中的函数调用、call_id、私有推理及图片块原样保留。

映射为会话内追加分配的 `e1`（证据）、`r1`（区域）、`d1`（图纸）、`o1`（观测）、`n1`（数值）。它们仅是既有 ID 的别名，不是新的证据、读回或完成信用。未知短 ID 拒绝执行；完整 ID 仍可使用，之后同样经过既有白名单、图纸范围、单位和来源校验。

完整映射保存在运行结果的 `model_context_codec.aliases` 以及日志的独立 `context_codec` section；它不进入模型输入。新会话建立新映射，不把旧任务别名直接带入当前任务。

## 模型视图

每个无状态请求重新构建自己的原文字典，不能依赖模型记住上一轮已被裁剪的消息。相同证据 ID 的原文在当前请求内只定义一次，其他位置使用 `evidence_id` 引用。不同证据 ID 即使文字相同仍保留独立身份；同一 ID 的冲突原文拒绝合并。

`source_groups` 按图纸和明确绑定的做法记录上提公共元数据，每组 `text` 按行表示 `[e1 r1] JSON字符串`。JSON 解码后的文字与原文逐字一致；换行、引号、反斜杠和看似引用标记的原文不会获得新的引用身份。已绑定记录的正文旁保留图框名、来源绑定状态和本页完整性，避免跨检查点后将“工程适用性未确认”误读为“正文未读”。相邻边界标题和单位条款不混入该记录组。图纸分组不表示同一构造，也不证明工程实例适用性，归属继续由标题、来源绑定、条件、分页和诊断说明。

同级 `items` 中明确存在且完全相等的来源绑定状态可提取到 `item_defaults`；不继承缺失值，不合并不同状态，也不提取单位、对象身份或原文内容。

做法查询视图在收集全部原文后省略重复片段解释和展示元数据，保留编号/歧义解释、来源绑定、单位条款、边界、分页与缺口。混合任务保留完整数值身份及片段计算信息。型式、编号和歧义项的计算禁用仍由统一数值模块执行。

较大的做法结果使用完整的结构化来源页，替代截断的 `preview_json`。完整版仍在原证据档案中，原工具输出大小限制和超限回滚保持有效。

## 纠错与审计

重复字段问题只保留一次，`repair_targets.issue_indexes` 指向同级 `field_issues`，失败条目本身保持原样。只有被结构化问题完整覆盖的反馈行才移除；全局缺项或调度错误继续保留。已验证结论和用户条件保持完整，仍须通过本轮最终校验，不能凭缓存状态直接发布。

编码统计记录原始/编码后的消息字符数、当前请求唯一原文数、别名数和任务视图。字符统计和本地 tokenizer 估计不等于服务 token；正式对比必须使用服务报告的 input/output/cached tokens。cached 是 input 的子集。

## 验证

`tests/test_model_context_codec.py` 覆盖原文往返、请求内去重、无状态重建、身份冲突、跨图同文、字面内容不替换、未知引用拒绝、编号/数值传递、公共字段上提、全局纠错反馈保留、片段投影不丢原文和 Responses 短 ID 全链路。

与 `test_unified_numbers.py`、`test_inline_list_grounding.py`、`test_r5_calculation_inputs.py`、运行时预算/桥接/日志回归共同执行。外墙真实验证采用同一快照、同一订阅模型和档位，不改变账号并发，不使用付费回退；同时检查来源覆盖及答案语义，不能把少读做法造成的 token 降低算作改进。

做法查询另提供“已读来源状态”任务视图：只列 source_bound、offset=0、complete_in_this_response、无后续页，且所有正文证据均在当前请求可见的记录。来源页完整性与工程适用性分别呈现；存储过、读过但本次上下文缺失、候选关联和未读分页均不能进入可交付清单。它不产生新原文、默认单位或完成信用。
