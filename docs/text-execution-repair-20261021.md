# 未完成文字目标的读取与计算调度修复

对照输入：`artifacts/text-repair-full12-20261021` 的首次成功发布记录；Q08 为第 3 次尝试。最终修订的相关题实测在 `artifacts/text-execution-verified-20261021`。第一版真实尝试保留在 `artifacts/text-execution-repair-20261021`，其 Q08 读取了 7A 并应用单位，但未执行计算，草稿 26mm 被校验拦下，促成第二版修复。第二版 `artifacts/text-execution-final-20261021` 的 Q08 计算并交付了 26mm 与30mm，但同页重读使楼梯再次漏读；第三版增加标题导航和语义同页保护。所有阶段保留，不以不同阶段的局部成功拼成一次通过。原问题、解析快照、Sol low、全局时间/工具/Token 预算保持一致。修复不是几何能力验收。

## 复现的断点

- Q08 已召回楼地面 7A，但候选读取按队列插入顺序排列，展示中缺少候选原文；跨条款分页的优先级还高于已命中来源。楼梯相关要求在 12 次调用处被关闭。
- Q08 算术分项因重复 get_evidence 两次而整个停滞，未执行的 calculate_facts 随之被关闭。
- 单位条款已经被读取，计算输入持久化了单位候选，但压缩后的模型上下文把候选丢掉，数值仍显示单位未确认。
- 文字计算的 units 操作被路由到几何工具；即使 calculate_facts 验证了每个操作数的单位，也没有对应的单位完成回执。

## 共享修复

1. 做法/构造/面层等问题的文字搜索，优先返回查询词命中的明确构造标题，保留全部原始匹配及分页；不以内部区域 ID 决定首屏。标题附带读取构造入口，仍不证明归属。已返回未读候选优先于扩展检索、跨条款分页；以所属要求对预览做词法排序，显式暴露前四个读取入口。预览仅用于导航，不产生证据或归属确认。
2. 同一构造来源、视图和偏移已经完整返回时拒绝重复读取，已有未读后页与目录仍可继续。重复无进展按实际动作及参数记录，阻止继续重放该动作，但允许同一要求执行其他来源或计算。全局重复失败保护保留。12 次分项上限改为有近期进展时最多额外 4 次，16 次硬停止；不改变全局预算。历史任务没有新进展记录时沿用原保守上限。
3. 默认单位只通过原有 calculate_facts 校验器预检已读数值、单位条款及范围；通过后向模型暴露可用 quantity 和独立 unit_evidence_id。预检不保存计算结果、不授予回执，不确定对象关系仍为 unconfirmed。编号/等级不充当厚度。
4. 文字算术的单位检查指向原文/计算路径。实际计算成功且所有输入单位通过校验后，才记录 units 回执；缺操作数时仍未完成。
5. 已有来源线性数值和本分项用户参照时，增加一次显式计算检查：模型须调用 calculate_facts 选择层次并执行，或用 missing_operands 记录具体缺项，然后才继续其他读取。同一运算已有计算/缺项记录后不反复阻塞；检查本身不自动选择操作数，不授予完成。共享读取分项的尺寸可以出现在后续计算输入中，但保留原要求来源、候选复用状态及对象未确认状态。
6. 提醒模型及时执行独立、已具备来源的算式。仅部分层次已知时可以给出明确条件的小计，不能当作完整总厚度，也不能把不同替代做法叠加。
