# 精简图纸工作台

界面保留左侧图纸文件、中间原图、右侧问答三栏，采用灰白背景和深色正文。没有顶部品牌栏，也不再常驻测量、找相似、识别、调试或下载按钮。

## 图纸与证据

- 左上角 `＋` 导入 DWG / DXF，也接受单文件拖放；原转换、解析和失败提示流程沿用。
- 点击文件切换当前图纸。正在分析时需等待完成或先停止分析。
- 左下角“原文与事实”按需打开原有检索、筛选、图纸结构、解析诊断和重新解析入口。
- 回答下方的编号引用只使用 `publishedCitations` 允许展示的来源；点击后缩放、定位、高亮并展开原文。实体、坐标等元数据收在“来源详情”。
- 跨图纸证据可切换原图并保留回答；切换后清空跨快照的追问运行标识，防止错误沿用上下文。
- 保留模型选择、订阅授权、检索方式、取消分析、历史运行和任务恢复。运行详情按需打开，不再自动改变工作区布局。

## 对话中的本地交互

普通语义问题继续使用原 Agent 的工具问答和证据校验。以下完整短句只用于发起需要浏览器交互的本地操作，回答标为“本地操作”，不会冒充模型执行：

| 输入 | 操作 |
| --- | --- |
| 下载原图 / 下载图纸 | 在回答内提供当前快照的可用文件链接 |
| 测量房间 | 在原图内部选点，沿用单位确认和几何测量流程 |
| 测量选中房间 | 使用当前定位的房间名称原文；未选证据时提示先定位 |
| 框选找相似 | 在原图框选样本，沿用所选图框或当前视野范围 |
| 识别当前视野的房间 | 沿用房间候选发现和单位确认流程 |
| 查看测量记录 | 打开原有测量记录 |
| 局部方法调试 | 打开原有范围与方法确认窗口，不自动启动调试 |
| 查看原文与事实 / 浏览图纸结构 / 查看解析诊断 | 打开对应资料窗口 |

选点、框选时显示临时提示，可点击“取消”或按 Esc 退出。包含范围、计算目标、其他分析内容的自然语言问题不会被这些精确短句拦截。

## 验证范围

前端回归覆盖导入、原图渲染、来源记录、引用筛选、测量展示、运行详情，以及本地交互与 Agent 问题的路由边界；Python 集成测试覆盖图纸导入、问答和证据。浏览器验证使用独立示例数据目录，不改动原有图纸数据；本地查询不构成真实模型端到端验收。
