## 本次修复

- 分析过程中，清空会话、资料窗口切换图纸和重新解析入口缺少一致保护，可能丢失前端运行状态。现提示先停止分析；解析过程中也阻止新提问。
- 更换布局/图框时仍残留选点状态或旧证据。现统一退出交互并清除来源选择；未加载图纸时安全返回。
- 从资料窗口浏览图框/布局后，原资料弹窗仍可能遮挡原图。现定位时同时关闭。
- 部分来源没有预生成预览地址时使用了错误的快照字段。现使用实际 drawing.id 构造链接。

新增回归覆盖运行保护、范围切换和跨图纸引用。保留既有 Agent、测量、来源证据和不确定性约束。
