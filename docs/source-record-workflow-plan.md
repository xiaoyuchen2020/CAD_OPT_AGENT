# 来源记录工作流实施与验收

分支：feature/source-record-workflow。以 17153b2 保存的主工作区快照为基线；不修改主工作区、账号并发或线上服务。

1. 任务路由：提取对象、动作、范围、条件、全量要求；多问与追问保留；复杂几何、计算及工程适用性走原 Agent。
2. 来源记录：复用表格、编号、数值、证据；分别记录分页、归属、引用和适用性；缓存绑定快照、源文件及解析版本。
3. 检索和打包：标题/表行/原文命中到完整记录；同区域多标题、分页、重复编号、引用、候选边界；完整记录预算及冷/热耗时。
4. 回答计划：逐记录选择、排序、分组、筛选、比较；原文由程序展开；遗漏/排除检查、解释独立校验、局部修复，不允许模型改写读取状态。
5. 产品集成：任务账本、取消、超时、用量；带已读证据回退；长记录拆分、分页折叠和定位；保留全部事实校验；功能开关。
6. 验证：先冻结真实图纸标准答案；多格式、同号、引用、编号小数、筛选、多问、追问、跨图；真实模型重复样本，质量/覆盖/证据、纠错、轮次、输入/输出/缓存、失败和冷/热时间分别报告。

实现与报告必须区分直接支持和保守回退，不能把候选数量、引用可回溯或一次测试成功当成工程判断正确。

六步的实现、验收和保守回退边界已逐项记录在 [实施与实际图纸报告](source-record-workflow-report-20261023.md)。当前功能默认开启，可通过 `CAD_SOURCE_RECORD_WORKFLOW=0` 或单次选择原 Agent 回到原流程。
