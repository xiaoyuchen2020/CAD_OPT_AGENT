# 已读原文工作集与重复读取恢复

默认启用 `CAD_READ_CONTEXT_OPTIMIZATION=1`，依赖模型上下文编码层。
设置为 `0` 可回退到改造前的上下文与纠错建议。证据、工具回执、原文跨度、
数值解析和最终答案校验仍使用原始会话账本；工作集不授予新的读取或完成凭据。

## 上下文

纯文本做法查找在每次模型请求内提供一次已读页面定义。来源只能来自本任务
`read_assembly` 观测与可解析的完整原文证据，不能从搜索摘要、模型生成内容、
或仅有历史 ID 的档案恢复。检查点即使省略了原文，下一轮仍从该账本恢复完整
页面及引用；视觉任务、继承会话和混合计算任务保留原路径。

已匹配旧页面的回执使用 `read_page_observation_id` 指向该请求内的定义。
只删除投影后相等的字段；额外诊断保留，不合并不同归属、分页或冲突版本。
模型调用参数、call ID、私有 reasoning 和图片内容保持原有协议。

页面的 `item_tables` 按 `columns` 解释 `rows`，连续字段集合分组保留项目顺序，
区分字段缺失与显式 null。原文保持在逐条证据标记中；数值目录独立保留编号、
量值、标识符和歧义状态。永久证据 ID 和完整元数据继续保存在后端。

`source_bound`、完整页和当前可见原文共同决定就绪提示；候选归属、未读分页、
工程适用性未知均不会因进入工作集而自动变成已确认或已完成。

## 纠错与重复读取

重复页判定共用 `matching_read_page`：同目标、同视图、同 offset，且已读至
页尾或原页覆盖本次请求大小，才视为重复。下一页和有必要扩大的不完整页仍可读。

重复请求仍返回 `SOURCE_PAGE_ALREADY_READ`，仍记录失败，不伪装成新读取成功。
反馈改为复用原观测，不再建议“修正参数后重调同一读取工具”；调度建议中的
已读同页也会过滤。涉及特定构造记录的答案校验错误附带对应已读页和证据 ID，
帮助修正报告字段。错误、字段问题、其他未读来源和完整诊断档案继续保留。

原有最终答案校验器及权限、预算、账号并发均不放宽。最终上下文预算检查
覆盖所有编码后的消息，Codex 单字符串接口也保留整个编码结果。

## 验证边界

测试覆盖检查点后的原文恢复、协议成对、来源冲突、缺失原文、部分页、候选页、
缺失字段与 null、重复读取建议，以及历史编号误判样本的完整校验回放。
实际节省须以同问题、同模型、同图纸和同答案覆盖要求下的服务端 usage 计量。
离线轨迹估算不代表真实 token 或缓存收益，恢复被旧检查点省略的原文也可能
使某轮输入变大。读取数、答案校验失败、重复读取拒绝及专用纠错轮次分别报告。

## 已读页与查找覆盖分开

`model-context-v1.4` 另外提供“待处理来源标题”导航。它来自已经返回的检索候选，
按用户问题中的构造类别与标题类别匹配，保留不同图框的同名标题。例如“顶棚
使用外墙涂料”不作为外墙做法标题。只有同一目标的正文读取回执才移出待办；
搜索摘要或其他记录的边界标题不能授予正文读取凭据。

该列表不增加模型预算、不强制声称全图穷尽，也不放宽部分答案的真实性校验。
它提示模型在预算允许时先处理相关未读图框和类型，防止整理两套已读示例后
过早结束。完整页状态和任务覆盖是两个独立条件，真实测试仍需固定覆盖标准。
