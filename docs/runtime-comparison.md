# AgentRuntime 开发对照结果（2026-10-14）

结论：三个运行时均已接通真实模型和通用 CAD 工具，保留 native 为默认实现。此次小样本没有显示替换 Harness 能提高答案发布成功率。外部 Harness 继续作为可选试验入口，回退需显式勾选，不能把回退结果计入所选 Harness 成绩。

## 固定条件与结果

四份已有真实 DXF，六个固定问题（概览、跨行条款、表格、适用范围、事实查询、信息缺失），每题每种运行时两次，共 36 次。三个运行时统一使用 DeepSeek `deepseek-flash`、非思考模式、六个工具及同一来源/答案校验器。模型请求上限 9、工具调用上限 16、总时间预算 180 秒；实验关闭回退。

| 运行时 | 发布成功 | 来源与关键词检查通过 | 成功回答耗时中位数 | 成功回答工具数中位数 | 全部尝试总 token |
| --- | ---: | ---: | ---: | ---: | ---: |
| native | 12/12 | 12/12 | 8.444 秒 | 6.5 | 422,216 |
| DeepSeek Harness 0.2.0-rc.2 | 10/12 | 10/12 | 8.096 秒 | 6 | 374,307 |
| Codex 0.144.5 | 11/12 | 11/12 | 7.691 秒 | 5 | 371,565 |

这里的“通过”只表示最终结构、引用来源及预设关键词通过开发检查，**不是答案语义正确率**。耗时仅统计成功回答，含每题进程启动成本；token 含失败尝试。失败较早结束、供应商缓存及不同上下文序列化都会影响耗时/用量，不能据此宣布某 Harness 更便宜或更快。样本重复两次不足以作统计优劣判断。

源文件 SHA、快照、初始事实集合、领域提示与工具 schema 哈希在 [manifest](../artifacts/runtime-comparison-final-20261014/manifest.json) 中。36 次源文件复核均未改变，成功结果实际运行时均与请求一致，没有回退。原始逐项答案、工具记录、证据字符范围和实体绑定见 [完整对照](../artifacts/runtime-comparison-final-20261014/report.html) 与同目录 JSON。

## 失败与修正

接入时发现 Codex Responses 的函数调用后可紧随助手文字；直接映射会破坏 Chat Completions 要求的工具消息顺序，导致 DeepSeek HTTP 400。桥接现已将同一回合的文字与函数调用合并到同一 assistant 消息，再接工具结果，已增加回归测试、通过真实跨行问题复测并重跑全批。初始失败批次保留在 `artifacts/runtime-comparison-20261014/`，不计入上表。

最终批次的三次失败均为 `ANSWER_VALIDATION_FAILED`，没有发布候选答案：

| 记录 | 具体原因 | 含义 |
| --- | --- | --- |
| overview--deepseek_harness--1 | 单条结论引用 10 个来源，超过上限 8 | 找到相关标题，但没有遵守输出约束 |
| overview--codex--1 | 单条结论引用 11 个来源，超过上限 8 | 同上；一次纠正后仍超限 |
| cross-line--deepseek_harness--2 | 材料等级结论写了“第2条”，引用却只有 a 子项，缺少编号来源 | 已找到厚度和材料，但逐条引用不完整；不能简单解释为没找到答案 |

两种外部适配器与原生循环都沿用一次答案纠正。当前 Pydantic 字段约束失败只反馈通用格式错误，未把“最多 8 个来源”明确反馈给模型，这是后续可小幅改善的共同问题；本轮保留固定校验行为，未为提升实验分数放宽约束。

## 语义复读发现

已复读 33 条发布答案，并对以下异常与引用原文作定向对照。没有完成独立建筑专业验收，也没有把自动检查状态改成语义通过。

- `missing--deepseek_harness--2` 把住宅章节中“200厚或100厚”的第（3）款称为非住宅 1.4 的“同节第(3)条”。引用文本是真实的，章节归属仍被误读。该句未改变“1.4 第（2）款厚度详建施图”的核心回答，却是应记录的范围错误。
- `missing--codex--1` 从“详建施图”进一步断言所需图纸在本文件之外。所引用条款没有证明文件外部关系；应只说需要继续核查对应图样。
- `scope--native--1` 末尾说非住宅条款“未见注明的……砂浆等级”，同一答案前文和原文却已列出 DMM5.0 专用粘结剂，表述存在歧义/自相矛盾风险。
- `scope--deepseek_harness--1` 比较段把 B07 与 A5.0 一起写入“强度等级表述”，混淆密度与强度，虽引用数值都在原文中仍不足以保证属性理解正确。
- 若干表格回答补充了隔声指标及单位、概览回答补充了文件构成。仅数字出现或标题候选命中无法证明这些额外推断；需要约束回答范围和补齐对应表头/图签来源。

这些观察说明下一步应优先改善共同的答案契约与证据关系，而不是继续更换运行时或提高循环轮数。MVP 可先要求简短回答；将文件元数据、来源文字和章节归属证据区分；给格式纠正提供明确字段反馈；把上述误读加入人工可复核的对照样例。
