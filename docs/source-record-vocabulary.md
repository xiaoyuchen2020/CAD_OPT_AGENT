# 来源记录词表与读取边界

词表定义在 `cad_agent/cad/source_vocabulary.py`，版本 `source-vocabulary-v2`。它控制来源检索，不确认工程对象适用性，也不把相近的构造视为等价。

## 同义写法与定向展开

- 外墙面、外墙饰面 → 外墙；内墙面、内墙饰面 → 内墙。仅用于做法记录身份。
- 天棚、顶棚面、天花、天花板 → 顶棚；雨蓬 → 雨篷；踢脚线 → 踢脚；屋顶 → 屋面。
- 不上人屋面 → 非上人屋面。长词优先，禁止被拆成“上人屋面”。
- “作法”只在查询语法中归一为“做法”，不改动引文。

| 父查询 | 单向扩展的子项 |
| --- | --- |
| 楼地面 | 楼面、地面、地坪 |
| 墙面 | 外墙、内墙、墙裙、护墙 |
| 顶棚 | 吊顶 |
| 踢脚 | 踢脚板 |
| 屋面 | 平屋面、坡屋面、种植屋面、上人屋面、非上人屋面、倒置式屋面、正置式屋面 |
| 楼板 | 架空楼板、保温楼板、分户楼板、地下室楼板、室外楼板、室内楼板 |
| 外墙 / 顶板 / 底板 | 相应的地下室子项 |
| 幕墙 | 玻璃幕墙、铝板幕墙、石材幕墙 |
| 门窗 | 门、窗 |
| 墙体 | 隔墙、砌体 |
| 变形缝 | 伸缩缝、沉降缝、抗震缝 |
| 地下室 | 地下室外墙、侧壁、底板、顶板、顶棚、楼板 |

楼板可组合地下室、室外、室内、架空、分户、保温等限定词；组合按完整身份处理，词序变化归一到同一限定集合。比如“地下室保温楼板”不能拆成“所有地下室构件或所有保温楼板”。

子项不反向展开父项，也不展开兄弟项。例如楼面查询不扩大为地面，吊顶查询不扩大为所有顶棚。楼地板、墙身、底板、顶板底等保留为独立名词，不强行等同于楼地面、墙面或楼板。

防水、保温、防潮、防火、防腐、防锈、油漆、涂料、防水涂膜、保温板、找平层、保护层是材料/功能字面条件。单独查询这类做法时检索包含该词的来源；这不等于推断构造具有相应性能。“含保温”仍可能命中“无保温”，需要语义判断的条件继续走 Agent。

## 编号、标题与局部映射

共享标题语法接受带材料修饰的标题、字母数字组合、全角编号和分隔符，例如“抛光砖楼面1”“顶棚-P1”“外墙－１”。语句中的“材料选用外墙1”“型号为楼地面2”不是标题。原文字节与字符起点保持不变。

“屋4”“内14”“L4”等可以作为精确编号查询，但不使用全局短码字典。短码的类别只能由同一连续表格中的明确名称/部位单元格建立局部映射；映射保留来源证据，冲突的映射不采用。裸短码不能凭字形确认为某种工程构造。

明确章节提供局部限定。例如同一阅读列的“五、楼面”下出现“楼地面1”，可凭章节原文把该记录归入楼面查询；遇到下一章节即停止继承。章节只能限定通用父类标签，不能把“地面1”改成楼面。这条关系保留独立证据，不写进全局同义词表。

检索命中与记录身份分别处理。正文出现“基层随内墙做法”，不会使踢脚记录变成内墙记录；顶棚基层出现“楼板”，也不会使顶棚成为楼板。显式引用依赖可独立保留，带 `reference_only` 标记。

## 记录类型与状态

- `layer_assembly`：构造层次来源。
- `material_clause`：材料、性能要求等条款。
- `node_record`：节点类来源。
- `source_section`：有标题和结束边界的章节原文，不声称是完整的单个构造层次。
- `table_group`：表格中包含多个子项，尚待拆分的来源分组；不得冒充一个连续层次序列。
- 外部/同图引用另用 `references`、`reference_state`、`reference_targets` 表达，读取引用不等于自动叠加做法。

`page_state=complete` 表示本条记录的分页读取完成；`binding_state=source_bound` 表示来源归属已绑定；它们均不代表工程适用性已验证。输出质量摘要单列已绑定、候选、未归属命中、未解决引用和排除数量，始终不宣称整图穷尽。

## 通用读取与校验

读取器以原始 CAD 文字实体作为可选定位锚点，允许一个解析区域内的不同表行分别读取。锚点必须属于请求区域；页复用和记录 ID 保留锚点/行边界区分。表格通过连续边框、表头、身份字段、层次序列和唯一性检查绑定，不按图纸文件名、哈希或指定原文特判。

独立图层的辅助横线可能切过合并单元格。读取器检查有完整表头和唯一身份的边框候选；不依据图层名称或颜色决定语义。合并表头可映射到多个子列；明确的“第 N 条改为”保留为非叠加替代说明。边界或子项归属不能确认时保留候选状态。

固定读取只把新的规范化页面记为遍历进展，不升级候选事实。重复页没有新增信用，工具、记录、页数和时间预算仍生效。策略停止使用 `AGENT_POLICY_STOP`，真正调用额度耗尽才使用 `AGENT_TOOL_LIMIT`。

服务器编译逐字原文时保存每段字符到原始证据的映射，并校验整个答案摘要和逐段相等性。因此来源中的“1.60mm”序号歧义或“上述”引用语言可原样保留；改写数字、普通生成文本和运算仍走原来的数值、单位、计算和归属校验。

几何候选、来源片段、表行绑定、局部短码表含负结果缓存，均绑定索引签名/读取器版本并限制容量；水平和竖向线段按坐标索引，减少重复全图扫描。

固定来源程序直接消费会话中的完整规范观测。对当前活动目标、快照、标题/实体锚点和分页起点完全匹配的读取，工具仅返回包含观测/归档定位的简短回执，完整条目、原文、绑定与几何仍在规范观测和归档中；随后逐项验证原文跨度。普通模型工具读取继续执行原返回大小限制，不因本流程放宽。

无可信身份表头、却包含多个明确标题的包络标为待拆分表格。只有服务器编译、摘要和字符跨度均通过验证的 `unknown` 候选原文可按转录呈现；`observed` / `derived` 归属断言与普通改写仍经过标题边界检查。
